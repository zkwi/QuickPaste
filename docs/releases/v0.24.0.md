# QuickPaste v0.24.0 发布说明

- Windows 自动粘贴支持剪贴板短重试和更宽容的编辑控件焦点恢复。目标不可用时可手动粘贴，钉住和托盘模式支持最近外部窗口。
- 快捷面板增加空格预览、仅复制、删除、文件筛选、右键管理和可选单击粘贴。
- 设置随 data/settings.json 迁移。管理页可清除普通记录，固定、集合和永久记录会保留。数据库整理会刷新实际文件占用。
- 捆绑 SQLite 已修复 [RUSTSEC-2026-0459](https://rustsec.org/advisories/RUSTSEC-2026-0459.html)。
