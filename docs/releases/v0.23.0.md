# QuickPaste v0.23.0 发布说明

修复微信等应用复制单张图片时只保留临时路径的问题，并补充本地故障诊断。

## 重点变化

- 微信等非资源管理器应用复制单张本地 PNG、JPEG、BMP 文件时，新记录保存独立图片内容，支持预览、OCR 和图片粘贴；源文件随后被清理也不会影响已捕获的图片。
- 资源管理器、来源不明和多文件复制继续按文件处理。损坏、不可读、超限或直接指向网络共享的图片文件回退为文件记录。
- 不迁移、不回填旧历史，不改变数据库 schema、保留期限和既有图片容量策略。
- 重复剪贴板警告每分钟最多一次，并区分剪贴板打开失败、必需格式读取失败、序列变化和图片读取失败。
- 日志补充版本、启动、正常退出和 Rust panic 调用栈；不记录 panic 正文或图片文件路径。

- 经维护者确认，补齐 Vue、构建链及 Rust TLS/证书校验相关安全补丁。生产 npm 依赖和 Rust 漏洞扫描均为 0 个漏洞；完整门禁包含 737 项前端和 329 项 Rust 测试。

## 闪退调查边界

已观察到的 Windows 原生堆损坏异常尚无明确调用栈，本版本不宣称修复该闪退。Rust panic 诊断不能捕获所有原生堆损坏或强制终止；进一步定位仍需 Windows 崩溃报告或本地转储。未启用自动上传、全局转储设置或额外常驻服务。
