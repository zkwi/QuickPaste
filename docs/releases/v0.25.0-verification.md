# QuickPaste v0.25.0 验证报告

验证日期 2026-11-12。构建环境为 Windows x64 MSVC、Node 22.14.0、npm 11.9.0 和 Rust 1.89.0。

## 修复与复审

- 必需格式连续读取失败三轮后，监听跳过确认未变的序号。剪贴板打开失败采用 800 毫秒、2 秒、5 秒的递增退避。观察到新序号后恢复读取。
- 富文本和文件的内部写入由私有剪贴板标记识别。独立复审发现识别标记后仍会读取文件元数据，已拆分捕获与粘贴核验路径。捕获识别自写或 Windows 不入历史标记后结束，粘贴核验保留序号和请求内容检查。
- 管理页右键删除和取消固定使用管理页的结果及焦点。搜索帮助支持 Esc 和外部点击。预览复制保留系统的文本选区行为。托盘目的地只接受管理和设置两个入口。

## 检查结果

- `npm ci` 和 `npm run check` 通过。47 项治理测试、753 项前端测试、337 项 Rust 测试通过。1 项共享系统剪贴板测试按原配置跳过。版本、隐私、运行时边界和许可证检查通过。
- 无界面 Chromium 使用合成样本，在 640 × 440 和 390 × 620 的浅色、深色界面验证帮助、右键菜单和预览按钮布局、键盘焦点、模拟组合键及选区复制。测试使用剪贴板替身。
- npm 生产依赖审计和 RustSec 漏洞项均为 0。RustSec 仍有 17 项与合并依赖后基线相同的上游警告。

## Windows 构建与产物

`npm run build:windows` 通过。已解包核对 NSIS 和绿色版，两包的四份第三方声明均与仓库逐字节一致。两包内的应用均为 x64、产品版本 `0.25.0`。NSIS 应用载荷与绿色版应用仅相差 Tauri 的打包标记。

- 绿色版主程序 19,065,344 字节，SHA-256 `FC80BD59E8B6579617F48371062F4754D2D32BF679430AB172A682A5D96C7BA9`。
- NSIS 应用载荷 19,065,344 字节，SHA-256 `236700CFBD31A09694820924B28B40E64F13F107949F2088ED87FD94F7B87D86`。

安装包和绿色版 ZIP 的 SHA-256 见 [发布说明](v0.25.0.md)。
