# QuickPaste v0.24.1 发布说明

- 托盘唤醒和钉住连续粘贴会保留仍存活的外部目标。钉住面板会随前台应用更新目标、图标和管理员标记。
- 粘贴前置条件受阻时可在快捷面板看到反馈。管理页粘贴使用最近的外部窗口，并保持管理窗口可见。
- 快捷面板删除后选中相邻记录。从搜索框打开预览后，关闭预览可接着搜索。
- 修复自身剪贴板写入因序号变化被重复收录的问题。仅复制遇到失效的源文件时会给出文件提示。
