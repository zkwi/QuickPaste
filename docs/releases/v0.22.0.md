# QuickPaste v0.22.0 发布说明

v0.22.0 将普通剪贴板历史改为按期限保留，不再因为达到 500 条或其他条数上限而提前删除仍在期限内的记录。本版本以标准 GitHub Release 分发，不标记为 Pre-release；真实机长期矩阵仍保留为待验证项，因此不表述为已经全面验收。

## 重点变化

- 普通历史不再限制条数，只提供 7、30、90 天三个保留期限；新安装默认 30 天。
- 固定内容和永久片段继续免于自动清理，不受期限或图片容量裁剪影响。
- 图片仍受独立的逻辑容量保护，新安装默认 256 MiB；已有安装和备份中的图片容量保持原值。
- 旧版“永不过期”策略升级后不会被自动改写或清理。设置页会把它显示为当前专用迁移状态，只有用户查看预计删除数量并确认 7、30 或 90 天后才事务性清理到期普通记录。
- 若期限写入或清理失败，确认框会保留原策略和数据并允许重试，不会出现界面已改变但数据库未提交的状态。

## 数据、安全与兼容性

- 设置 schema 升级到 7，SQLite schema 升级到 13；旧 `maxRecords` / `max_records` 字段继续保留以兼容设置、IPC 与备份，但规范为 JavaScript 最大安全整数，原生层不再执行条数裁剪。
- 升级和恢复会保留已有图片容量及期限；旧版空期限不会在启动、迁移或恢复时触发静默删除。
- 数据目录、剪贴板格式、搜索分页、OCR、管理员粘贴协议和单条载荷安全上限均未改变。
- 主程序继续保持普通用户权限；安装包仍只提供当前用户范围的 Windows x64 NSIS，不生成 MSI、MSIX 或 APPX。

## 尚待真实机验证

- 标准/紧凑窗口、完整 DPI 与多显示器组合下的长期设置操作。
- 微调、微软拼音及其他第三方输入法组合下的长期键盘与焦点兼容。
- 500 次暖唤起、10,000 次外部普通目标粘贴和 100,000 次独立捕获。
