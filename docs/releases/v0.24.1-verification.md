# QuickPaste v0.24.1 验证报告

验证日期 2026-11-12，Windows x64 MSVC，Node 22.14.0、npm 11.9.0、Rust 1.89.0。

## 修复与复审

- 托盘和钉住面板按存活的 HWND 与进程 ID 识别普通粘贴目标。钉住时前台事件刷新目标，应用图标在后台读取，事件发出前核对目标与会话。
- 各粘贴入口在写剪贴板前固定本次目标。快捷面板在目标与策略就绪后进入自动粘贴。确认剪贴板内容被替换时显示原因，必要时恢复面板。管理页使用最近外部窗口，并保持可见。
- UAC helper 继续校验一次性请求、时限、焦点和精确剪贴板序号。helper 返回失败时可复核剪贴板是否被实际替换。
- 删除后保持相邻选择，并按原操作位置恢复焦点。预览关闭后可回到发起预览的搜索框。短时自写去重接受向前变化的系统序号，保留签名匹配和一次性消费。
- 仅复制时即时复核本地文件路径。UNC 和网络盘沿用已有状态，路径检查止于重解析点。失效文件显示对应提示。[Windows 驱动器类型 API](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getdrivetypew)
- 独立只读复审发现的目标取样顺序、UAC 失败回显、网络路径探测与图标读取阻塞四项问题均已修复。

## 检查结果

- npm ci、npm run check 通过。47 项治理测试、749 项前端测试、335 项 Rust 测试通过。共享系统剪贴板往返保留为显式测试。版本、隐私、运行时边界及许可证检查均通过。
- 前端回归覆盖目标驻留和事件更新、搜索与删除焦点、预览的 Space / Esc、失效文件，以及剪贴板被替换时的反馈。
- npm 生产依赖与 RustSec 的漏洞项均为 0。RustSec 仍有 17 项上游警告，依赖版本沿用 v0.24.0。
