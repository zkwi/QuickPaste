# QuickPaste v0.25.0 发布说明

- 剪贴板打开失败时逐步拉长重试间隔。必需格式连续读取失败三轮后，等待下一次剪贴板变更。
- QuickPaste 通过专用标记排除自己写入的富文本和文件，随后从外部复制相同内容可以正常入库。Windows 不入历史标记也适用于图片。
- 完整管理页支持右键删除、固定和取消固定。删除后清理多选状态，并保留相邻记录或搜索框的键盘焦点。
- 搜索帮助补全快捷键说明，按 Esc 或点击外部即可关闭。预览支持用按钮或 Ctrl+C 仅复制，正文已选中时保留系统复制。
- 托盘菜单新增「管理剪贴板」和「设置」入口。
